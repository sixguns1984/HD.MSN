# GitHub upload checklist

1. Create an empty repository and copy the contents of `HD_MSN_analysis_code` into its root.
2. Select a repository license and replace `docs/LICENSE_NOTICE.md` with the corresponding `LICENSE` file.
3. Add the final repository URL to the manuscript Data Availability statement.
4. Do not upload controlled participant MRI, clinical data, raw donor-level files, access credentials, or local environment files.
5. Keep `MANIFEST.csv` and `SHA256SUMS.txt` with the release so readers can verify file integrity.
6. If public input data are mirrored, retain their original accession numbers, provider citations, and reuse terms.

The release archive contains scientific analysis and figure-generation scripts. Temporary document-editing utilities, rendered manuscript files, raw data, intermediate matrices, and result images are intentionally excluded.

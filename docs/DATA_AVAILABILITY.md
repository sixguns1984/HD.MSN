# Data identifiers

This repository distributes analysis code and provenance records. Participant MRI and clinical data are not included.

Public molecular resources used by the scripts are identified by accession or DOI:

- Allen Human Brain Atlas, processed with `abagen`
- Zenodo DOI `10.5281/zenodo.20301898`
- GEO `GSE281069`
- GEO `GSE180928`
- GEO `GSE233387`
- GEO `GSE233408`
- GEO `GSE64810`
- GEO `GSE3790`, platforms `GPL96` and `GPL97`
- GEO `GSE79666`
- Spatial transcriptomic reference `STDS0000242`

Each dataset is analyzed separately at its documented biological-sample level. Raw expression matrices from different sequencing platforms or studies are not pooled.
